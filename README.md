# Hi, I'm Liam 👋

I go by **Watire** online. I'm Nix-pilled, IT-pilled, and Sway-pilled, among many other pills.

I work in IT support by day, and self-host and run far more servers than I actually need by night.

## 🛠️ What I'm working on

- **Hosting Cluster**: six old HP machines running NixOS and k3s on their own isolated network, with a NixOS gateway doing the routing.
  - [`bunchwebhost/nixos`](https://github.com/bunchwebhost/nixos): NixOS configs for the nodes and gateway
  - [`bunchwebhost/cluster`](https://github.com/bunchwebhost/cluster): the k3s side

- **My NixOS Desktop**: a flake-based config with home-manager, running Sway and Waybar.
  - [`liambunch/nixos`](https://github.com/liambunch/nixos)
